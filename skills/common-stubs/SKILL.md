# Common stubs

Use Repertoire to discover a stub and obtain its verified asset path and usage
instructions:

```bash
repertoire stub list common-stubs
repertoire stub get common-stubs/editorconfig
```

Follow the returned instructions when applying the asset. Repertoire provides
the source material but does not change project files.
